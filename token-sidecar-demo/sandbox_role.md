沙箱在真实生产环境中叫 **Vault / KMS**（如 HashiCorp Vault、AWS KMS、Azure Key Vault），是一个**独立部署的安全密钥管理服务**，是整个体系的**信任根**。

请求者**不在沙箱里跑**。沙箱是一个独立服务，它：
1. 持有**私钥**（生产环境存 HSM 硬件安全模块中）
2. 为经过**身份认证**的 Sidecar 签发限域令牌
3. **审计日志**完整记录每一次操作
4. 支持**密钥轮换**（新旧密钥共存，平滑过渡）
5. 支持**令牌吊销**（即时使令牌失效）

在 K8s 中的部署关系：
```
┌───────────────────── Pod ─────────────────┐
│  ┌────────────┐    ┌──────────────────┐   │
│  │ 业务容器    │◀───│ Sidecar (Envoy)  │   │
│  │ (App)      │    │ 通过 iptables    │   │
│  │            │    │ 透明拦截流量      │   │
│  └────────────┘    └──────┬───────────┘   │
└───────────────────────────┼───────────────┘
                            │ workload identity (mTLS)
                            ▼
              ┌─────────────────────────┐
              │  沙箱 (Vault 集群)       │
              │  · HSM 保护私钥         │
              │  · 签发/吊销令牌        │
              │  · 审计日志            │
              │  · 密钥轮换            │
              └─────────────────────────┘
```
